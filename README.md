# NEXORA SMART EDU (V1)

## Teacher Attendance SaaS Platform

### Quick Start
1. Install: pnpm install
2. Env: Copy .env.example to .env
3. DB: docker compose -f infrastructure/docker/docker-compose.dev.yml up -d
4. Run: pnpm dev
